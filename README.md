# FacultyAssist AI

Intelligent Faculty Work Management & Academic Automation System.

## Modules
1. Assignment Evaluation — cosine similarity / TF-IDF-style baseline
2. Attendance Risk — decision-tree style classifier
3. Question Paper AI — constraint-based generation
4. Performance Analyzer — K-Means style clustering
5. Timetable Optimizer — constraint satisfaction
6. Weak Student AI — KNN-style feature distance
7. Faculty Task Planner — priority scheduling
8. Result Analytics — descriptive analytics and clustering concepts

## Design
Fast, responsive glassmorphism interface. No external AI API key is required. Current prototype stores data locally in browser localStorage so it works as a zero-setup static application.

## Next production layer
A hosted database/auth backend can be connected without changing the algorithm modules.
